# QaudFInder 개발 과정

[English](DEVLOG.md) | **한국어**

> macOS용 경량 파일 탐색기 **QaudFInder** — 한 창을 2×2(4칸)로 나눠 칸마다 다른 폴더를 띄운다.
> 개발 기간: 2026-11 · 기획·테스트: Tissant · 구현: Claude Code

---

## 1. 프로젝트 한눈에 보기

| 항목 | 내용 |
|---|---|
| 목적 | Finder 대신 쓰는 가벼운 파일 탐색기. 한 창에 폴더 4개 |
| 기술 | Swift + SwiftUI, 파일 목록은 AppKit(`NSOutlineView`, `NSCollectionView`) |
| 외부 라이브러리 | **없음** (Apple 기본 프레임워크만) |
| 앱 크기 | 약 **1.8 MB** |
| 코드 양 | Swift 15개 파일 + 도구 2개, 약 3,600줄 |
| 필요 환경 | macOS 27.2 이상 |
| 앱 이름 | `QaudFInder` — 처음엔 오타였지만, 흔한 이름과 다른 **차별화 포인트**로 보고 그대로 유지 |

### 개발 원칙 (처음부터 끝까지 지킨 것)

1. **버전 단위 진행** — 한 버전을 끝내면 직접 테스트하고, 통과해야 다음 버전으로.
2. **매번 빌드 검증** — 코드를 바꿀 때마다 `xcodebuild`로 오류·경고가 없는지 확인한 뒤 테스트.
3. **안전 우선** — 파일 삭제는 **휴지통 이동만**. 완전 삭제 코드는 한 줄도 없음. 실제 파일을 바꾸는 테스트는 테스트 전용 폴더에서만.
4. **가볍게** — 외부 패키지 금지, 화면 아이콘은 SF Symbols.
5. **Git 기록** — 버전마다 커밋해서 언제든 되돌릴 수 있게.

## 3. 단계별 기록

### 0단계. 인계와 준비 (claude.ai 채팅 → Claude Code)

- 채팅에서 만든 v2(`ContentView.swift` 한 파일, 약 770줄)를 인계 문서로 넘김.
- 작업 규칙·설명 방식·병합 사양을 Claude Code용 지침 파일로 옮김 → 다음 세션부터 자동으로 읽음.
- 프로젝트가 **폴더 동기화 방식**이라 `QaudFInder/` 안에 `.swift` 파일을 만들기만 하면 Xcode에 자동 포함됨을 확인.
- **결정**: 병합할 칸 선택은 `⌘`+위쪽 막대로 유지.

### v3. 목록 구조 변경 + 선택·키보드

**왜 했나**: v2에서 SwiftUI `List`의 끌기와 선택이 충돌해서 직접 그린 목록으로 우회했는데, 그 대가로 *여러 파일 끌기*와 *끌어서 범위 선택*을 잃었음. Finder와 같은 AppKit 부품으로 바꿔 되찾기로 함.

| 한 일 | 내용 |
|---|---|
| 파일 분리 | `Models/`(데이터), `Views/`(화면)로 나눔 |
| 리스트 보기 | `NSTableView` — 이름/수정일/크기/종류 열, 열 제목 클릭 정렬, 열 너비 기억 |
| 아이콘 보기 | `NSCollectionView` — 러버밴드(사각형) 범위 선택 |
| 끌기 | 여러 파일 한꺼번에, Finder처럼 "이름 위에서 끌면 파일 끌기 / 빈 곳에서 끌면 범위 선택" |
| 키보드 | 방향키, `⇧`+방향키, `⌘A`, `⌘↓`/`⌘↑`, 이름 입력으로 찾기 |
| 훑어보기 | `QLPreviewPanel` 직접 연결 → 미리보기 창을 띄운 채 방향키로 다른 파일 보기 |
| 활성 칸 | 지금 키보드를 받는 칸에 테두리, `Tab`/`⇧Tab`으로 칸 이동 |

- **진행 방식**: 리스트 보기까지 만든 뒤 한 번 중간 테스트 → 통과 후 나머지 진행 (가장 큰 작업을 쪼개서 위험 줄이기).
- **피드백**: "삭제 기능이 없어서 불편" → v4 최우선으로 배정.

### v4. 파일 조작

| 기능 | 단축키 / 방법 |
|---|---|
| 휴지통으로 이동 | `⌘⌫` (완전 삭제 아님, "되돌려 놓기" 가능) |
| 이름 바꾸기 | `Return` → 그 자리에서 편집, 확장자 앞부분만 선택 |
| 새 폴더 | `⇧⌘N` → 만들자마자 이름 편집 |
| 복사·붙여넣기 | `⌘C` / `⌘V` (Finder와도 주고받기 가능) |
| 이동 | `⌥⌘V`, 또는 끌기 시작 후 `⌘` |
| 경로 복사 | `⌥⌘C` |
| 우클릭 메뉴 | 열기·훑어보기·이름 바꾸기·복사·휴지통·경로 복사·Finder에서 보기 |
| 함께 새로고침 | 같은 폴더를 보는 다른 칸도 자동 갱신 |

- **피드백 반영**: 상태줄의 "OO GB 사용 가능"(모든 칸에 똑같이 보여 불필요) → **현재 폴더가 차지하는 용량**으로 교체. 하위 폴더까지 더해야 해서 **백그라운드 계산** + "계산 중…" 표시.
- `Return`이 "열기" → "이름 바꾸기"로 (Finder와 동일). 열기는 더블클릭·`⌘↓`·`⌘O`.
- **검증**: 실제 파일 대신 임시 폴더에서 새 폴더·이름 바꾸기·복사·이동·자기 자신 안으로 복사 막기를 자동 테스트.

### v5. 사이드바 + 탐색 편의

- **끌어 놓기 규칙 확정**

  | 끄는 것 | 놓는 곳 | 동작 |
  |---|---|---|
  | 사이드바 항목 | 칸 | 그 칸이 해당 폴더로 이동 |
  | 칸의 파일·폴더 | 다른 칸 | 복사 (끌기 시작 후 `⌘` → 이동) |
  | 칸의 폴더 + **`⌥`** | 다른 칸 | 그 칸이 해당 폴더로 이동 |
  | 칸의 폴더 | 사이드바 | 즐겨찾기에 추가 |
  | Finder의 파일 | 칸 | 복사 |

- 접고 펼 수 있는 사이드바 (`⌃⌘S`), 기본 즐겨찾기 5개 (데스크탑·문서·다운로드·홈·응용 프로그램)
- 즐겨찾기 추가(끌어 놓기·우클릭), 끌어서 순서 변경, 우클릭 제거, 모두 저장
- `⇧⌘G` 폴더로 이동: 전체 경로, `~` 경로, 상대 경로, 파일 경로(그 파일 선택) 지원

### v6. 마무리 편의

| 기능 | 내용 |
|---|---|
| 백그라운드 복사 | 큰 파일 복사 중에도 앱이 멈추지 않음. 여러 작업은 줄 서서 차례로 |
| 진행률 | 오른쪽 아래에 `1.2 GB / 4 GB · 30% · 대기 1개`, ⓧ로 취소 |
| 취소 시 | 덜 복사된 항목은 **휴지통으로** |
| 다른 디스크로 이동 | 복사가 끝난 뒤 원본을 **휴지통으로** |
| 종료 확인 | 복사 중 `⌘Q` → "계속 진행 / 취소하고 종료" |
| 자동 새로고침 | 다른 앱에서 파일을 바꿔도 0.4초 안에 칸이 갱신 |
| 숨김 파일 | `⇧⌘.` 칸별 토글, 흐리게 표시, 설정 저장 |

- 백그라운드 복사가 가장 큰 작업이라, 먼저 작은 시험 프로그램으로 macOS 복사 함수(`copyfile`)의 진행률·취소 동작을 확인한 뒤 본 구현.

### 마무리. 여러 창 · 아이콘 · 설치

- **여러 창**: `⌘N`으로 여러 창 가능. 다만 칸 상태 기억이 창끼리 섞이는 문제 → 새 창은 기본 폴더로 시작, 기억은 첫 번째 창만.
- **앱 아이콘**: 파란 바탕 위 2×2 폴더, 왼쪽 위 노란 폴더 = 활성 칸. 외부 도구 없이 Swift 코드로 직접 그림 (`Tools/make-icon.swift`).
- **설치 자동화**: `./Tools/install.sh` 한 줄로 Release 빌드 → 응용 프로그램 폴더 설치. 예전 버전은 휴지통으로.

### v7. 미리보기 · 폴더 펼치기 · 아이콘 크기

며칠 직접 써 본 뒤 나온 요청 세 가지.

| 기능 | 내용 |
|---|---|
| 파일 내용 미리보기 | 사진·PDF·동영상·문서는 아이콘 대신 내용이 보이는 썸네일 (`QuickLookThumbnailing`). 처음엔 기본 아이콘 → 준비되면 교체, 한 번 만든 건 기억 |
| 폴더 펼치기 | 리스트 보기를 `NSOutlineView`로 바꿔 폴더 아이콘 왼쪽 `›`로 그 자리에서 펼치기. `→`/`←`, 새로고침해도 펼친 상태 유지 |
| 아이콘 크기 슬라이더 | 아이콘 보기 버튼 `⌘`+클릭 → 팝오버. 연속 슬라이더 Small 50% · Normal · Big 150% · Huge 200%, 즉시 적용, **칸별**, 재시작 시 Normal |

- **결정**: 아이콘 크기는 칸별로, `›`는 Finder처럼 아이콘 왼쪽에.
- **추가 수정**: 아이콘 보기에서 훑어보기를 띄운 채 방향키로 움직이면 창이 닫히던 문제 해결 (아래 9번).

### 1.1.0. 편의 기능 + 설정 창

GitHub 공개(Release v1.0) 뒤 첫 버전. 이때부터 버전 번호를 `주.부.수` 형식으로 바꿔, v7 다음을 **1.1.0**으로 정했다(새 기능은 가운데 숫자를 올림). 기능이 많아 두 단계로 나눠 중간에 한 번 테스트했다.

| 단계 | 기능 | 내용 |
|---|---|---|
| 1 | 다음으로 열기 | 우클릭 하위 메뉴. 기본 앱 "(기본)"이 맨 위, 다른 앱, "기타…". 여러 파일이면 모두 열 수 있는 앱만 |
| 1 | 서비스 | 표·아이콘 보기가 "선택한 파일을 넘겨줄 수 있다"고 macOS에 알려(`validRequestor`, `writeSelection`), 다른 앱의 서비스가 Finder처럼 우클릭 메뉴에 붙음 |
| 1 | 경로 입력 | 오른쪽 위 "폴더로 이동" 버튼과 입력 창을 없애고, 칸 위쪽 경로를 더블클릭(또는 `⇧⌘G`, 이동 메뉴)하면 그 자리에서 입력칸으로 |
| 1 | 즐겨찾기 정리 | 경로 글자 대신 북마크로 저장 → 이름 바꾼 폴더를 따라감. 휴지통으로 간 폴더·없어진 폴더는 정리, 연결이 끊긴 외장 디스크(`/Volumes/…`)의 폴더는 흐리게 남김. 예전 목록은 처음 켤 때 자동으로 옮김 |
| 1 | 격자 간격 | 아이콘 크기 팝오버 아래 50~150% 슬라이더. 눈에 보이는 간격(이름 여백 + 칸 사이 + 줄 사이)을 함께 조절 |
| 1 | 아이콘 크기 | 50~300%로 확장, 눈금 6개. 200%를 넘으면 미리보기를 더 큰 크기로 다시 만들고, 미리보기 기억 용량은 약 200MB로 제한 |
| 2 | 설정 창 | `⌘,`·톱니바퀴. 탭: 일반(칸별 시작 폴더) / 보기 / 파일 조작(휴지통 확인, 폴더 용량, 끌어 놓기 기본 동작) / 사이드바 / 단축키 / 고급(초기화). 기본값은 1.0과 같은 동작 |
| 2 | 단축키 바꾸기 | 10개 기능의 단축키를 바꿀 수 있음. 글자만 누른 키, macOS가 쓰는 키, 이미 쓰는 키는 거절. 고정 단축키·마우스 동작도 같은 탭에 목록으로 |

- **테스트 후 수정**: 슬라이더 창이 화면을 가려 폭 60%·높이 약 50%로 줄임 → 글씨 10% 키움 → 아이콘 크기 눈금 글자 대신 같은 간격 눈금 6개 → 경로 입력은 한 번 클릭 대신 더블클릭으로.
- **다음 버전으로 넘긴 것**: "시작할 때 칸 배치(가로×세로, 최대 6칸)"는 칸 구조를 새로 만드는 1.2.0(자유 분할)에서.

## 4. 겪은 문제와 해결

| # | 문제 | 원인 | 해결 |
|---|---|---|---|
| 1 | `ObservableObject` 관련 빌드 오류 | 최신 Xcode는 모듈 import를 엄격하게 검사 | 해당 파일마다 `import Combine` 직접 추가 |
| 2 | SwiftUI 목록에서 끌기 대신 범위 선택이 됨 | `List(selection:)` + `.onDrag` 충돌 (macOS) | AppKit `NSTableView`/`NSCollectionView`로 교체 |
| 3 | 폴더 감시 코드에서 `open` 오류 | 같은 이름의 `PaneModel.open(_:)` 메서드와 충돌 | `Darwin.open` / `Darwin.close`로 명시 |
| 4 | 복사 취소해도 "성공"으로 돌아옴 | `copyfile`은 콜백에서 중단해도 0(성공)을 반환 | 취소 여부를 따로 기록해서 판단, 덜 된 항목은 휴지통으로 |
| 5 | `self captured before initialized` 오류 | 초기화가 끝나기 전에 클로저에서 속성 사용 | 지역 변수로 먼저 계산한 뒤 넣기 |
| 6 | 아이콘을 넣었는데 Dock엔 빈 아이콘 | Dock이 첫 실행 때(아이콘 없을 때) 모습을 캐시 | `lsregister -f`로 재등록 → 앱 재실행 (안 되면 `killall Dock`) |
| 7 | 아이콘 폴더 탭 이음새가 움푹 패임 | 탭과 몸통의 둥근 모서리가 겹침 | 탭을 몸통 안쪽으로 깊게 겹쳐 그림 |
| 8 | 여러 창의 상태 기억이 섞임 | 상태를 칸 번호(0~3)로만 저장 | 첫 번째 창만 저장(`WindowPanes`), 나머지는 기본 폴더 |
| 9 | 아이콘 보기에서 훑어보기 중 방향키 → 창이 닫힘 | 컬렉션 뷰는 "선택 해제 → 새로 선택" 두 단계로 알려 주는데, 그 사이 선택이 잠깐 비어 보임 | 훑어보기 갱신을 한 박자 미뤄 최종 선택 기준으로 판단 |
| 10 | 한글 입력 상태에서 단축키를 바꾸면 "⌥⌘ㅅ"처럼 표시 | 눌린 글자를 입력 소스 기준으로 읽음 | 키 위치 번호로 영문 글자를 정함 (Finder 메뉴와 같음) |
| 11 | 우클릭 메뉴에 "서비스 ▸" 대신 영어 항목이 바로 보임 | macOS는 서비스가 몇 개뿐이면 하위 메뉴로 묶지 않음 | 정상 동작. 필요 없는 항목은 시스템 설정 → 키보드 → 키보드 단축키 → 서비스에서 끔 |

## 6. 남은 과제 (선택)

- 병합 상태를 앱을 다시 켜도 기억할지 (현재는 재시작 시 풀림) → 1.2.0 자유 분할에서 "배치 기억"으로 해결 예정
- 되돌리기(`⌘Z`) — 현재는 휴지통의 "되돌려 놓기"로 대신
- 펼친 하위 폴더 안을 다른 앱이 바꿨을 때의 자동 새로고침 (현재는 ⟳ 버튼)

## 7. 돌아보며

- **작게 쪼개고 매번 확인**: 모든 버전을 "만들기 → 빌드 → 직접 테스트 → 커밋" 순서로 진행해서, 문제가 생겨도 원인을 바로 찾을 수 있었다.
- **위험한 기능은 안전장치부터**: 파일을 바꾸는 기능은 전부 휴지통 경유로 설계해서, 실수해도 되돌릴 수 있다.
- **불확실한 기술은 먼저 시험**: 진행률처럼 처음 쓰는 기능은 작은 시험 프로그램으로 동작을 확인한 뒤 본 코드에 넣었다.
- **실사용 피드백이 우선순위를 바꿈**: "삭제가 불편", "용량 표시가 불필요", "미리보기가 필요" 같은 의견이 다음 버전의 1순위가 됐다.
